# Ссылочный снимок установленного Windows launcher

Эти скрипты ожидают собственную папку work с concord/, runtime/, local-data/ и соседней outputs/. Это расположение действующей копии, не standalone installer. Рантаймы PostgreSQL16.15, Redis5.0.14.1, LiveKit1.13.9, Mailpit1.31.5, Caddy2.11.7 и Node24.19 нужны отдельно; их бинарники, пользовательские базы и ключи исключены. run-local.ps1 в исходном окружении использует Node из кеша Codex; на другой машине нужно настроить путь. Для чистой системы предпочтительна Docker-команда из docs/LAN.md. Не копировать чужой local-data ради запуска.
